# DB-4H Fix8 — Relative Block Placement + Gap Controls

## Scope
- Reference-block selector for Body elements, including Tables.
- Place Above and Place Below actions.
- Physical Gap in mm.
- Align Left / Center / Right with the reference block.
- Match Reference Width.
- Placement clamps to Header/Footer-aware Body bounds.
- Manual drag and overlap remain available after placement.

## Example
Select the blank details Table, choose the customer-name Text as the reference, set Gap = 4 mm, then click Place Below. The blank table is positioned immediately below the text while remaining inside the usable Body region.
