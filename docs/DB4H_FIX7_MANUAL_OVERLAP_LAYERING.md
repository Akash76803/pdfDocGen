# DB-4H Fix7 — Manual Overlap + Layering

- Smart Insert only affects the initial insertion position.
- Manual drag intentionally allows elements to overlap existing Body blocks, including tables.
- The currently selected element is temporarily raised so it remains draggable while crossing another block.
- Properties now provides Bring Front, Forward, Backward and Send Back controls.
- Layer changes participate in DB-5A Undo/Redo.
- Existing page/body bounds constraints remain unchanged.
